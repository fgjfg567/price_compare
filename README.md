# مساعد التسوق من أمازون — دليل التشغيل

## الفكرة
- **التطبيق** (Flet): بحث في أمازون السعودية، عروض، كوبونات، وكل روابط المنتجات تتحول إلى روابط عمولتك.
- **لوحة التحكم** (`admin/index.html`): صفحة ويب تتحكم بالعروض والكوبونات والمؤقت ومعرّف العمولة، وتظهر التغييرات للمستخدمين خلال ثوانٍ **بدون تحديث التطبيق**.
- **الخادم**: قاعدة Firebase Realtime Database المجانية (التطبيق يقرأ منها، واللوحة تكتب فيها).

## 1) إعداد Firebase (مرة واحدة — مجاني)
1. ادخل console.firebase.google.com ← **Add project** (عطّل Analytics).
2. القائمة اليسرى **Build ← Realtime Database ← Create database** (اختر الموقع الأقرب، وابدأ بـ Locked mode).
3. انسخ **رابط قاعدة البيانات** من أعلى صفحة Realtime Database (يشبه `https://xxxx-default-rtdb.firebaseio.com`).
4. **Build ← Authentication ← Get started ← Email/Password ← Enable**، ثم تبويب **Users ← Add user** وأنشئ حساب المشرف (بريدك + كلمة مرور قوية). انسخ **User UID** الظاهر بجانبه.
5. **Project settings (⚙️) ← General ← Your apps ← أيقونة </> (Web)** ← سجّل تطبيق ويب، وانسخ قيمة **apiKey**.
6. عودة إلى **Realtime Database ← Rules**: الصق محتوى `firebase_rules.json` بعد استبدال `ضع_هنا_UID_حساب_المشرف` بالـ UID الذي نسخته ← **Publish**.
   (بهذا القراءة عامة والكتابة لحسابك فقط.)

## 2) ضبط التطبيق
افتح `src/app_config.py` وضع `FIREBASE_DB_URL` (رابط الخطوة 3). أما معرّف العمولة فتضبطه من لوحة التحكم.

## 3) لوحة التحكم
افتح `admin/index.html` في المتصفح (من جوالك أو حاسوبك، أو ارفعه على GitHub Pages للوصول من أي مكان) ← الصق **apiKey** والرابط ← سجّل الدخول.
- **الكوبونات:** المؤقت (رسالة + مدة بالدقائق أو الساعات)، وإضافة كوبون (الاسم يكتبه المشرف + نص الكوبون)، وزر حذف.
- **العروض:** نوع العرض + رابطه، وزر حذف. الرابط يتحول داخل التطبيق لرابط العمولة.
- **الإعدادات:** **معرّف الشريك (Tag)** — ضروري لاحتساب عمولتك، وخيار إخفاء الأسعار، وإعلان أعلى البحث، ونص الإفصاح، ورابط سياسة الخصوصية.

## 4) بناء التطبيق
نفس خطوات GitHub السابقة (يفضَّل **مستودع جديد**): ارفع كل المحتويات، ثم Actions ← Build Android APK ← Run workflow ← حمّل الـ APK من Artifacts.
قبل البناء غيّر `org` في `pyproject.toml` إلى اسم خاص بك (اسم الحزمة لا يتغير بعد النشر).

## 5) النشر على Google Play
حساب مطوّر (رسم لمرة واحدة)، رابط سياسة خصوصية (انظر `privacy_policy_template.md` وضعه في الإعدادات)، نموذج Data safety (التطبيق لا يجمع بيانات شخصية)، وحزمة AAB موقّعة: استخدم `build_aab.yml` (لم أجربه) بعد إنشاء مفتاح توقيع وحفظ أسراره في GitHub.
